# 电磁感应与楞次定律

独立实验版本 0.1.0，协议 v2，状态格式 1。选题对应《物理学教程》第四版下册 §12-1、§12-2（111–122 页）。

## 物理模型与符号

- 条形磁铁用轴向磁偶极子近似，磁矩大小为 2 A·m²。磁铁沿同一侧的导轨移动，磁铁中心到线圈平面的距离 $d$ 取 7–26 cm，不进入线圈。线圈用半径 $a=4$ cm 的相同圆匝表示，匝数 $N$ 可调。场景中的线圈匝数仅作示意。
- 磁通量 $\Phi$ 按单匝计，正法线从线圈指向磁铁。取 $s=+1$ 对应 N 极朝线圈，$s=-1$ 对应 S 极。把轴向偶极场的法向分量在整个圆面上积分，得到 $\Phi(d)=-s\,\mu_0 m a^2/[2(a^2+d^2)^{3/2}]$，不把线圈中心的磁场当作全盘均匀磁场。
- 从磁铁一侧看，约定逆时针为正。使用 $\mathcal{E}=-N(\mathrm{d}\Phi/\mathrm{d}d)\dot d$ 和 $I=\mathcal{E}/R$。模型把闭合回路视作纯电阻，忽略自感、涡流、感应场对磁铁运动的反作用和导轨摩擦。轴向箭头只表示方向，不表示磁场强弱。符号与感应定律对照 [OpenStax：法拉第定律](https://openstax.org/books/university-physics-volume-2/pages/13-1-faradays-law) 与 [楞次定律](https://openstax.org/books/university-physics-volume-2/pages/13-2-lenzs-law)。

| N 极朝向线圈 | 单匝磁通量       | 电动势 | 从磁铁侧看到的电流 |
| ------------ | ---------------- | ------ | ------------------ |
| 靠近         | 负值，绝对值增大 | 正     | 逆时针             |
| 停留         | 负值且不变       | 零     | 无                 |
| 远离         | 负值，绝对值减小 | 负     | 顺时针             |

改为 S 极朝线圈会反转磁通量、电动势和非零电流的符号。静止的磁铁仍可有磁通量；只有磁通量变化才使该闭合回路产生净电动势。

## 操作与回看

1. 沿导轨拖动磁铁。保持按住鼠标但停住，可记录磁通量平台和零电动势；松手则停止记录，末端保持静止。也可聚焦磁铁并用方向键、Home、End 和空格操作。
2. 拖动时以 1/60 s 固定间隔记录位置，磁铁跟随手的目标位置，速度上限为 0.60 m/s。两相邻位置之间用线性位移和该段的速度计算磁通量及其导数；折点处采用刚完成那一段的速度。场景、曲线、读数和回看游标共用此模型；慢放只改变推进游标的速度。
3. 「演示」提供一次靠近、停留、远离的可重复记录。三个标记可对照同一距离下反向运动，或在磁铁附近停住。也可用键盘控制时间滑块，或点击右侧曲线定位。
4. 在手动记录终点再次拖动会继续记录（总计最多 12 s）；从较早的画面或演示接手会在当前位置开始新记录。清空记录和改变实验参数也会保留当前位置、开启新记录；切换图表或图层不会。刷新后恢复记录、游标和偏好，但不自动播放。

## 本地验收

从仓库根目录运行：

```sh
bun test experiments/electromagnetic-induction/tests
bunx playwright test --config experiments/electromagnetic-induction/tests/playwright.config.ts
just build-exp electromagnetic-induction
```

首次使用 Playwright 时先运行 `bunx playwright install chromium`。独立配置在 4176 端口使用生产预览，覆盖鼠标拖动与停留、键盘、方向变化和正负号、双语明暗单屏、暂停恢复与首次离线进入。
