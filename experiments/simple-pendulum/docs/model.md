# 单摆：小角近似与非线性周期

独立实验，版本 0.1.0、协议 v2、状态格式 1。选题对应《物理学教程》第四版上册 §5-1（120–121 页）。两种模型使用同一摆长、重力和初始条件，便于直接比较周期。

## 假设和模型

- 质点通过无质量刚性杆绕固定支点运动，忽略阻力、支点摩擦与其他外力。选用刚性杆而不是细线：在水平线以上静止释放时，细线无法提供保持同一圆轨道所需的约束。摆长取 0.50–2.50 m、重力加速度取 1–20 m/s²，释放角取 −170° 到 170°；不模拟 180° 处的不稳定平衡或转动。
- 以垂直向下为零，向右为正，两种模型都从 $\theta(0)=\theta_0$、$\dot\theta(0)=0$ 开始。非线性模型满足 $\ddot\theta=-(g/L)\sin\theta$；小角近似用弧度并以 $\theta$ 代替 $\sin\theta$，得到 $\theta_\text{小角}=\theta_0\cos(\sqrt{g/L}\,t)$。
- 设 $k=\sin(|\theta_0|/2)$。小角周期为 $T_0=2\pi\sqrt{L/g}$；非线性周期为 $T=4\sqrt{L/g}\,K(k)$。$T/T_0$ 只依赖释放角幅度。0° 时不会振动，界面只显示作为极限值的 $T_0$，不显示非线性周期或启用回摆按钮。
- 从能量守恒得到 $\dot\theta^2=(4g/L)[k^2-\sin^2(\theta/2)]$。以 $\sin(|\theta|/2)=k\sin\psi$ 代换，最低点到当前角度的时间比例由第一类不完全椭圆积分给出。程序用算术—几何平均求 $K(k)$，并用分段 Simpson 积分和区间反解恢复每一帧的物理角度，再用四分之一周期对称性获得方向和速度。积分定义与 AGM 关系见 [NIST DLMF 19.2.4](https://dlmf.nist.gov/19.2.E4) 和 [19.8.5](https://dlmf.nist.gov/19.8.E5)。
- 图中红色箭头只表示切向加速度 $a_t=-g\sin\theta$；它不包含向心加速度。有符号的切向速度为 $L\dot\theta$。能量图使用单位质量的动能 $L^2\dot\theta^2/2$、势能 $gL(1-\cos\theta)$ 及其和，单位 J/kg。小角近似摆球只提供运动参考，不使用其偏差来计算非线性模型的能量。

## 使用与对照

1. 拖实心摆球，或聚焦后用方向键设置释放角，按播放让两个模型从同一点静止释放。实心球是非线性模型，虚线球是小角近似。场景按摆长归一化绘制，数值、周期和能量仍使用输入的实际摆长。
2. 载入 10° 和 120° 预设，比较周期。以 1.00 m、9.81 m/s² 为例，小角周期始终约为 2.006 s；非线性周期在 10° 时约为 2.010 s（延长 0.19%），在 120° 时为 2.754 s（延长 37.29%）。还可用 165° 预设观察接近顶部时的慢运动。
3. 「小角近似回摆」定位到 $T_0$，「非线性回摆」定位到 $T$；两者会暂停在同一时刻供对照。「首次过最低点」与「另一侧转折」分别定位到非线性 $T/4$ 和 $T/2$。时间滑块支持键盘，摆角 / 能量图也可点击回看。时间范围为两个非线性周期。
4. 改变任一参数或载入预设后，两种模型一起回到静止释放点。切换图表或隐藏虚线摆球不改时间；慢放只改变推进速率。刷新后恢复参数、时间和观察偏好，并保持暂停。

## 本地验收

从仓库根目录运行：

```sh
bun test experiments/simple-pendulum/tests
bunx playwright test --config experiments/simple-pendulum/tests/playwright.config.ts
just build-exp simple-pendulum
```

首次运行 Playwright 前用 `bunx playwright install chromium`。独立配置在 4175 端口运行生产预览，测试两种桌面尺寸和主题 / 语言、周期对照、键盘和鼠标、回看与状态恢复，以及首次离线进入。
