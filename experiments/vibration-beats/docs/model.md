# 振动合成与拍

独立实验 `vibration-beats`，首版 0.1.0，协议 v2，状态格式 1。选题对应《物理学教程》第四版上册 §5-4（127–130 页），只模拟同一直线上的两个独立、无阻尼简谐位移。不是两个耦合振子，不计算力、能量或声压，也不把振幅包络当作第三个振源。

## 模型

- 振幅 $A_1,A_2$ 为 0–4 cm，频率 $f_1,f_2$ 为 0.50–3.00 Hz。第一源初相位固定为 0°，第二源可在 −180° 到 180° 调节。模型以秒计时、以弧度求值。
- 矢量 $Z_i=A_i e^{\mathrm{i}(2\pi f_i t+\varphi_i)}$ 的水平投影是 $x_i$。首尾相接得到 $Z=Z_1+Z_2$，合位移 $x=\operatorname{Re}Z=x_1+x_2$。场景、读数、曲线和游标共用解析求值，不依赖帧率。
- 相位差为 $\Delta\varphi=2\pi(f_2-f_1)t+\varphi_2$，合矢量长度为 $R=\sqrt{(A_1-A_2)^2+4A_1A_2\cos^2(\Delta\varphi/2)}$。$x$ 落在 $[-R,R]$ 内；$R$ 不是 $|x|$。等幅、初始同相时，合位移也能写成快余弦与慢余弦的乘积；振幅包络取慢因子的绝对值。
- 两源都有非零振幅且频率不同，包络在相差 $0\bmod 2\pi$ 时最大 $A_1+A_2$，在相差 $\pi\bmod 2\pi$ 时最小 $|A_1-A_2|$。相邻包络峰之间的时间为 $T_{\text{beat}}=1/|f_2-f_1|$，不是它的两倍。频率相近时才明显表现为快振动与慢包络；频率相等或任一源关闭时没有循环变化的包络，不显示拍周期。

## 操作

1. 先以等幅、1.00 Hz 与 1.20 Hz 运行：拍周期为 5.00 s，2.50 s 时出现第一次反相。用「下一次反相」「正交 90°」观察合矢量、相对相位差 $\Delta\varphi$ 与瞬时包络圆；按钮到末端后回到循环中的第一次对应时刻。
2. 切到右栏底部「探索」标签，载入「不等振幅余留」比较反相时仍保留 1.50 cm 的包络，载入「同频锁定反相」观察持续抵消，或载入「慢拍细辨」对比高频载波与 10.00 s 慢包络。也可直接在旋转矢量平面拖动 $Z_2$（或聚焦后用方向键）调节初相位 $\varphi_2$，或将任一振幅调到零。
3. 「时域波形」显示随游标移动的局部时间窗（四个较慢源周期），避免把几十个快周期挤在一张小图中。「振幅包络」覆盖完整回看范围，以虚线标出正负包络界限 $\pm R$，内部叠加低对比度合振动载波 $x(t)$ 与当前位移实心点。完整回看区间至少覆盖四个较慢源周期；有拍时也至少覆盖两个完整拍周期。
4. 拖图或用时间滑块（方向键、Home、End）回看。改参数、载入场景或回到起点后暂停；切换观察方式和显示图层不改时间或倍率。重开或刷新时始终暂停，恢复上次的时间、振源和显示偏好。

## 本地验收

从仓库根目录运行：

```sh
bun test experiments/vibration-beats/tests
bunx playwright test --config experiments/vibration-beats/tests/playwright.config.ts
just build-exp vibration-beats
```

首次运行 Playwright 前用 `bunx playwright install chromium`。独立浏览器配置在 4174 端口启动生产预览；覆盖物理读数同步、键盘和拖动、两种桌面尺寸和主题 / 语言、页面隐藏暂停、状态恢复，以及首页完整缓存后首次离线进入。
