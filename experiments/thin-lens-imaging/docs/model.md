# 薄透镜成像

独立实验 0.1.0，协议 v2，状态格式 1。选题对应《物理学教程》第四版下册 §13-4（153–156 页）。

## 模型与符号

- 空气中的理想会聚薄透镜，光从左向右，在透镜平面 $x=0$ 折射；画出的透镜厚度仅为示意。焦距 $f$ 取 8–24 cm，物距 $u$ 取 5–72 cm，均以 0.5 cm 步进。物体底部位于主光轴，物高固定为 2.4 cm。不模拟像差、遮挡以外的真实透镜结构、衍射或光传播时间。
- $u>0$、$f>0$。薄透镜公式为 $1/f=1/u+1/v$，有符号放大率 $M=-v/u$，像高 $h_\mathrm{i}=M h_\mathrm{o}$。$u>f$ 时 $v>0$、$M<0$：透镜另一侧形成倒立实像。$u<f$ 时 $v<0$、$M>0$：与物体同侧形成正立虚像。$u=f$ 时没有有限像距或放大率，读数为「—」，不绘制像箭头。参见 [OpenStax：Thin Lenses](https://openstax.org/books/university-physics-volume-3/pages/2-4-thin-lenses)。
- 平行入射线经像方焦点，过光心线不偏折；物方焦点线出射后平行于主光轴。物体在焦点内时，第三条入射线的反向延长线才经过物方焦点。第三条光线在 $u=f$ 时不能到达透镜，或在交点超出图示半口径 8 cm 时不画；结果仍由薄透镜公式与前两条光线确定。$u=f$ 时从物体顶端发出的前两条出射线**彼此**平行，但不一定平行于主光轴。
- 只对虚像绘制出射光的反向延长线，虚线不是实际光路。场景横向范围 ±80 cm、纵向范围 ±12 cm，纵向放大约 2.73 倍以便观察；图上的角度不是物理角度。近焦时像可能超出场景：只裁切绘图，不修改像距、像高或放大率。

## 操作与对照

1. 拖动物体改变物距，或聚焦后按方向键，按住 Shift 时步长增大。也可用左栏滑块设置焦距和物距。
2. 点击「焦点外 · 2f」「焦点内」「恰在焦点」依次对照。默认 $f=16\,\mathrm{cm}$ 时，$u=32\,\mathrm{cm}$ 得到 $v=+32\,\mathrm{cm}$、$M=-1$；$u=10\,\mathrm{cm}$ 得到 $v\approx-26.67\,\mathrm{cm}$、$M\approx+2.67$。在 $u=16\,\mathrm{cm}$ 时观察平行出射。
3. 「成像读数」显示像的位置和有符号的像高；「三种情况」按当前焦距并排计算。切换虚像延长线只改变辅助图层，不移动物体，也不改变读数。
4. 该实验比较静态构型，不需要播放和时间轴。刷新后恢复焦距、物距以及延长线和观察面板偏好。

## 本地验收

从仓库根目录运行：

```sh
bun test experiments/thin-lens-imaging/tests
bunx playwright test --config experiments/thin-lens-imaging/tests/playwright.config.ts
just build-exp thin-lens-imaging
```

首次使用 Playwright 时先运行 `bunx playwright install chromium`。独立配置在 4180 端口运行生产预览，验证实像、虚像、焦点处平行出射、近焦超出画面、拖动与键盘、双语明暗单屏、状态恢复和首次离线进入。
