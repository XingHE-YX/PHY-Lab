# 机械波实验模型与操作规则

实验 ID：`mechanical-waves`；实验版本 **0.1.0**；状态格式 **1**。这是路线中的第 2 项独立实验。平台保持 0.1.0，弹簧振子保持 0.2.0。模型、双语文案、SVG 场景、曲线、状态和资源全部位于 `experiments/mechanical-waves/`，仅通过公开插件协议接入平台。

## 模型范围

使用一维、均匀、无耗散的线性横波模型，传播速度为常量 `c`。介质质点的横坐标 `x` 固定，只沿 `y` 方向运动。纵向位移在场景中作示意放大，坐标轴、探针和读数仍使用真实单位。这里不根据张力和线密度求解实际绳子的非线性形状。

传播模式的右端无反射。反射模式仅模拟右端的一次反射；左边界输入入射信号并允许反射波离开。观察长度 `L` 不代表两端固定的共振腔长，也不限制可选频率。

驻波模式直接展示两列等频、等幅、反向行波形成的已建立状态。它有独立的初始条件，不表示从静止开始驱动的瞬态过程。反射模式中的连续波保留启动传播，可以观察与已建立驻波的区别。

边界反射和逐点叠加参照 [OpenStax：Interference of Waves](https://openstax.org/books/university-physics-volume-1/pages/16-5-interference-of-waves)；驻波的波节、波腹及间距参照 [OpenStax：Standing Waves and Resonance](https://openstax.org/books/university-physics-volume-1/pages/16-6-standing-waves-and-resonance)。本实验没有实现该教材中两端约束的离散共振频率。

## 信号、传播与反射

定义 `s(u)=0`（`u≤0`），脉冲输入为：

```text
s(u) = σ A sin²(πu/τ),  0 < u < τ
s(u) = 0,              u ≥ τ
```

`σ=+1/-1` 分别对应向上 / 向下发波。脉冲位移与速度在两端连续，加速度在端点有分段跳变；端点按静止分支显示。波包在空间中的长度为 `cτ`，没有单一的正弦周期。

连续驱动使用 `s(u)=A e(u) sin(ωu)`，其中 `ω=2πf`、`T=1/f`，第一个周期的包络为 `e(u)=[1−cos(πu/T)]/2`，之后 `e=1`。速度和加速度包含包络的一、二阶导数，不能直接套用恒定振幅公式忽略启动。

```text
yᵢ(x,t) = s(t − x/c)
yᵣ(x,t) = R s[t − (2L−x)/c]
y(x,t)  = yᵢ + yᵣ
```

传播模式 `R=0`。固定端 `R=−1`，反射位移反相，右端总位移与横向速度为零；自由端 `R=+1`，反射同相，右端总斜率为零，重叠时位移可达到入射波峰的两倍。

`vᵧ=∂y/∂t`、`aᵧ=∂²y/∂t²`，空间斜率按 `(vᵣ−vᵢ)/c` 求值。各段满足 `∂²y/∂t²=c² ∂²y/∂x²`。波前未到达的位置保持静止；返回的脉冲离开左端后不再返回。

## 已建立的驻波

令 `q=2π/λ=ω/c`、`λ=c/f`，选取以下一致的相位约定：

```text
yᵢ = A sin[ωt + q(L−x)]
yᵣ = R A sin[ωt − q(L−x)]

固定端：y = 2A sin[q(L−x)] cos(ωt)
自由端：y = 2A cos[q(L−x)] sin(ωt)
```

固定端在 `t=0` 具有最大空间包络，自由端在 `t=0` 整体位移为零而部分质点速度非零。改变右端边界会按新模型从头开始。

局部振幅为对应空间因子的绝对值乘以 `2A`。相邻波节间距为 `λ/2`，波腹振幅为 `2A`；波节在所有时刻的位移和速度都为零。绳子在某个瞬间变直时，波腹依然可能具有最大速率。固定端的 `T/4` 预设专门用于观察这一差别。

波节与波腹标记来自公式计算的空间位置，不从离散曲线的瞬时过零点猜测。观察段可能没有某一类位置，相应定位按钮禁用；`A=0` 时全介质静止，隐藏这两类标记并说明无法区分。

## 参数与显示

| 参数         | 可调范围 | 单位 | 含义                           |
| ------------ | -------- | ---- | ------------------------------ |
| 入射振幅 `A` | 0–0.4    | m    | 单列行波的幅度，非驻波波腹振幅 |
| 传播速度 `c` | 1–6      | m/s  | 扰动传播速度，非质点横向速度   |
| 频率 `f`     | 0.2–2    | Hz   | 连续波或驻波的频率             |
| 观察长度 `L` | 4–12     | m    | 当前展示的空间范围             |
| 波包时长 `τ` | 0.4–2    | s    | 单次脉冲持续时间               |

`λ=c/f`、`T=1/f`、`L/c` 和 `cτ` 随参数计算。波包模式不显示不存在的正弦波长与周期。

场景保持固定物理横坐标；探针在横向选择跟踪位置，并非把质点拖成新的波形。蓝色表示横向位移，绿色箭头表示该质点的横向速度，红色读数表示横向加速度。传播方向单独标注 `c`，避免将质点运动与波的前进混为一谈。

主场景和空间剖面共用合成波 / 入射波 / 反射波开关。介质质点、探针读数、自由端滑环始终由合成波计算。关闭图层不改变模拟时间、播放状态、物理参数或场景比例。驻波标记可单独隐藏。

右侧在“质点记录”和“空间剖面”间切换。前者固定 `xₚ` 查看 `y(t)` 或 `vᵧ(t)`，后者固定 `t` 查看 `y(x)`，并列出探针处的两项分量与合成位移。不同单位不共用一个纵轴。

## 单屏操作

- 顶栏提供播放 / 暂停、重置和 `1× / 0.5× / 0.25×` 慢放。标题旁切换传播、反射与驻波。
- 左栏按“波源 / 介质”分组调参。修改物理参数或边界会暂停并从 `t=0` 开始；切换观察视图和显示图层保留运动状态。
- 中央拖动蓝色质点选择跟踪位置；方向键每次移动 0.1m，Shift 每次移动 0.5m，Home / End 定位两端。右侧滑块提供等价操作和带单位的可访问读数。
- 拖动时间轴或点击时间曲线暂停回看；点击空间剖面移动探针。关键按钮定位发射波峰、到达边界、返回探针，或驻波的 `T/4`、`T/2`、`3T/4`。波节 / 波腹按钮循环选择下一处位置。
- “公式 / 探索”在右栏就地替换；探索按钮载入对应的暂停预设。完整模型通过说明弹窗查看，Escape 关闭并恢复焦点。观察标签支持方向键和 Home / End。

常规核心操作在 1280×720、1440×900 的桌面内容区内完成，中英文与明暗主题共同验收。探索详情和说明弹窗允许内部滚动；低于目标高度时提供可访问滚动兜底。

## 同步、状态与离线

所有图形、箭头、游标和实时值从同一个 `waveAt(params,x,t)` 求值，不用独立动画模拟物理运动。时间曲线的标记直接计算当前时刻，不采用最近的离散采样点。时间回看无积分历史依赖。

脉冲在离开观察段后自动暂停：传播模式为 `L/c+τ`，反射模式为 `2L/c+τ`。时间游标和存档恢复也遵守这一上限。连续波与驻波按窗口显示时间，支持继续运行和窗口内回看；总模拟时间上限为 100000s。

实验仅通过 `context.storage` 保存状态，键为 `phy-lab:experiment:mechanical-waves:state:1`。保存参数、时间、速率、探针位置比例、参数分组、观察视图、曲线量和图层偏好。恢复时校验结构与有限值并补齐默认字段；重进页面始终暂停。离开页面、页面隐藏或实例释放时停止时钟、保存状态并清理监听器。

本实验由既有构建脚本自动发现，独立生成完整资源清单和内容指纹。首次首页缓存完成后，尚未进入过的机械波实验也可断网打开和刷新。更新沿用 [发布与更新规范](release-and-update.md)，不修改平台或弹簧实验版本。

## 验证

模型测试检查波峰按 `c` 传播、波前因果性、解析导数与波动方程、固定 / 自由边界、波节静止、波腹振幅与间距，以及零振幅、异常参数和存档恢复。

浏览器验收检查场景 / 曲线 / 读数共享时间，图层切换不改状态，探针拖动与键盘操作，驻波定位与探索预设，双语 / 双主题 / 桌面尺寸矩阵，首页缓存后的首次离线访问，独立存档和离开时的动画清理。平台既有更新、回退和弹簧流程继续运行完整回归。
