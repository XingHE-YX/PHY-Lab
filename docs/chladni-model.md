# 克拉尼图形：模型与操作

独立插件 `chladni-plate`，版本 0.1.0，状态格式 1。实现使用现有 TypeScript、Lit、KaTeX，以及浏览器原生 WebGL2、Web Audio；不新增框架或运行依赖。平台仍为 0.1.0。

## 操作

首页搜索“克拉尼”“驻波”或“Chladni”进入。

1. 点击一个“共振模态预设”，再点击顶栏“开始”。砂粒逐渐离开振动强的区域，形成低振幅区域附近的纹路。默认频率约 201.42 Hz；可以先比较模态 13、21、22。
2. 左栏“驱动”调整频率、力幅值和阻尼比；“板材 / 撒沙”调整边长、厚度和粒数。铝材参数固定。改变物理参数或激励位置会暂停、重新撒沙并回到零周期。
3. 中央选择“移动激励”或“移动测点”，点击板面或拖动 S / P。两个标记均支持方向键、Shift 加大步长、Home 回到中心；P 还可通过右栏坐标框输入。坐标以板心为原点，俯视时 x 向右、y 向下，单位 cm。
4. 右栏切换“看沙纹”“看振型”“看共振”。前两项提供测点的位移 / 速度 / 加速度曲线；共振图可点击、拖动或用方向键改变频率。辅助图层、视角、测点和观察切换保留当前物理时间与砂粒。
5. 暂停后拖动 N 时间轴回看；“回到起点”重现同一批砂粒的初始分布，“重新撒沙”更换种子，“清空砂粒”保留裸板观察。顶栏提供 1×、0.5×、0.25× 观察速度，不提供单步按钮。
6. 播放时产生振动音。右上角设置 → 实验设置 → “静音”可关闭声音，选择自动保存。静音不暂停画面；慢放不降低音高。默认允许声音，但进入页面、恢复存档时保持暂停与安静，点击播放后才启动声音。

俯视用于观察纹路，倾斜用于观察放大的瞬时弯曲。图层不会改变参数与时间。核心流程在 1280×720 与 1440×900 的桌面内容区内完成；完整假设与探索问题放在“模型说明”浮层。

## 薄板与支承

模型为方形、均匀、各向同性的铝薄板：边长 L = 0.24–0.50 m，厚度 h = 0.6–1.5 mm，杨氏模量 E = 70 GPa，密度 ρ = 2700 kg/m³，泊松比 ν = 0.33。默认 L = 0.36 m、h = 1 mm。

采用 Kirchhoff–Love 弯曲理论：

```text
D = E h³ / [12(1 − ν²)]
D ∇⁴w + ρh ∂²w/∂t² = p
U = D/2 ∫∫ [wₓₓ² + wᵧᵧ² + 2νwₓₓwᵧᵧ + 2(1−ν)wₓᵧ²] dx dy
```

外缘不施加位移或斜率约束，自由边界作为弯曲能量的自然边界条件处理。中心用 3×3 个固定**位移**支承点近似小块固持；归一化坐标 ξ = 2x/L、η = 2y/L 均取 −0.1、0、0.1，整体跨度为边长的 10%。这不是对有限面积理想夹具的精确接触计算，也不能理解成整块板外缘固定。

照片没有给出准确材料、尺寸和夹具信息，本实验复现砂粒显示二维弯曲驻波的现象，不标定照片中的装置。薄板频率不能套用一维弦或二维张紧膜的频率公式。

## 模态与计算

`model/plate.ts` 使用归一化 Legendre 张量积试函数进行 Rayleigh–Ritz 计算，中心约束在系数空间消元，保留质量正交的前 24 个模态。生产表采用每个方向 18 阶试函数，保存在 `model/modes.json`。

归一化坐标下的特征值 λⱼ 转换为：

```text
ωⱼ = (4/L²) √[D/(ρh)] √λⱼ
fⱼ = ωⱼ/(2π)
```

因此同材质、相似支承下，固有频率随 h/L² 缩放。改变边长或厚度不需要重新求解模态。默认尺寸下，第 13、21、22 阶约为 201.42、317.91、387.60 Hz。

表的最大投影特征残差约 1.69×10⁻⁷；质量正交性、九点位移约束、方板重复频率以及 16 阶到 18 阶的收敛对比均有测试。前 24 阶频率在该阶数对比下变化小于 3%，**这不是对真实装置误差的上界**。支承近似、有限模态与有限试函数均会产生误差。

特征求解只用于生成表，不进入动画运行路径。常规响应、网格和粒子计算使用 TypeScript；当前无需引入 Rust WASM。

重新生成：

```sh
bun experiments/chladni-plate/tools/generate-modes.ts
bun experiments/chladni-plate/tools/generate-thumbnail.ts
just test
just build-exp chladni-plate
just catalog
```

缩略图也由实际模态与砂粒状态生成，不手绘假波节线。

## 驱动、曲线与能量

激励为点 S 处的简谐力 `F₀ cos(ωt)`，每阶使用相同阻尼比 ζ = 0.005–0.08。质量归一化约定下，各阶模态质量 `M = ρhL²/4`：

```text
Qⱼ = F₀ Φⱼ(S) / {M [ωⱼ² − ω² + i 2ζωⱼω]}
W(x,y) = Σ Qⱼ Φⱼ(x,y)
w(x,y,t) = Re[W(x,y) exp(iωt)]
v = ∂w/∂t，a = −ω²w
```

这是带阻尼的**周期稳态解**，不包含启动暂态。预设只将驱动频率设为某阶固有频率，不强制只显示该阶形状；最终仍由所有保留模态的幅值、相位与激励耦合共同决定。固有频率预设不等于承诺整条响应曲线的精确峰位。S 接近某模态波节时，对该模态的激励会很弱。

共振图纵轴为复振幅的**空间**均方根：`√(Σ|Qⱼ|²)/2`，不是再做时间平均后的均方根位移；图上已注明 RMS、μm。主导模态按 `ωⱼ²|Qⱼ|²` 选择。曲线围绕固有频率加密采样，展示的频带限制在已保留低阶模态内，高阶响应仍有截断误差。

测点曲线的横轴为物理时间 ms，三种物理量分开选择并标明单位；蓝色为位移、绿色为速度、红色为加速度。振型观察给出模态动能与弯曲势能：

```text
Eₖ = ½ M Σ q̇ⱼ²
Eₚ = ½ M Σ ωⱼ²qⱼ²
平均耗散功率 = Σ ζMωⱼω²|Qⱼ|² = 平均输入功率
```

受迫有耗散系统不宣称瞬时机械能守恒。测试用独立差分核对速度、加速度，并核对平均功率收支、力幅值线性关系和阻尼对单模态响应的影响。

## 砂粒与统一时间

所有显示共用周期数 `N ∈ [0,80]`，相位 `2πN`，物理时间 `t=N/f`。默认每墙钟秒推进 4 个周期；0.5× / 0.25× 再减慢。画面明确标出“相位慢镜头”，不能把该速度视为真实高频振动速度。

砂粒使用固定 1/16 周期的内部步长，沿归一化稳态振幅平方的负梯度迁移；迁移强度受振动加速度影响，并叠加有种子的微扰。越过外缘的粒子离开板面。种子、参数与周期数相同时，回看和存档恢复的砂粒位置可重现；检查点减少回看时的重复计算。

砂粒迁移是**教学近似**，没有精确计算重力接触、跳跃、碰撞、摩擦、颗粒尺寸或堆积厚度。它的无量纲迁移时间不能预测真实聚集耗时。驱动力为零时，板面与砂粒保持静止。

砂粒依据的是 `|W|`，不是某个瞬间的 `w=0`。多模态复响应未必形成完整的严格波节线，因此辅助图层称“低振幅线”，统计“低振幅区砂粒”，避免误导。

## 声音与绘制

音效使用浏览器原生 Web Audio 正弦振荡器，频率严格跟随实际驱动频率 f；音量按空间与时间均方根板面速度压缩映射，并限制输出增益。它用于听辨频率和振动强弱，**不模拟真实板面的声辐射、音色或砂粒碰撞声**。很低的驱动频率可能听不见，不做额外升调。

只有点击播放或运行中取消静音时才创建 / 恢复音频上下文。静音、暂停、回看、物理参数变化、切后台和离开时淡出；离开后释放振荡器和音频上下文。延迟的恢复请求不能让已经暂停的实验重新发声。无声音 API 时显示说明，保留其他操作。

原生 WebGL2 用 65×65 网格绘制实际稳态场的瞬时弯曲，并绘制砂粒。形变按当前峰值示意放大，画面标明倍数；读数保留实际单位。倾斜视角的点击通过同一变形网格拾取。辅助振幅场表示稳态大小，不能与瞬时位移颜色混淆。

WebGL2 不可用或上下文丢失时回退 Canvas 2D 俯视图，保留参数、时间与砂粒，禁用倾斜视角。无额外渲染框架、在线纹理或音频文件。

## 状态、离线与边界

参数、周期数、砂粒种子与数量、清空状态、测点、观察模式、图层、视角、速度与静音选择通过 `context.storage` 隔离保存。恢复时校验结构、有限值、范围和当前可计算频带；缺失字段使用默认值，重新进入保持暂停。

实验资源进入独立清单，沿用平台完整缓存、完整性校验与更新规则。首次首页显示“可离线使用”后，尚未进入过的本实验也能断网打开、刷新和继续操作，声音同样不需要联网。

忽略剪切变形、转动惯量、大挠度、非线性、真实夹具接触和高阶工程精度。超过板厚三分之一的峰值振幅时，界面提示减小驱动力。该提示是教学模型的适用性提醒，不是材料破坏判据。

验收覆盖模型约束与收敛、参数边界、损坏存档、确定性砂粒回看、测点和曲线同步、变形板拾取、双语明暗单屏、首次离线进入、显卡回退、音频输出 / 静音 / 资源释放及实验退出。
