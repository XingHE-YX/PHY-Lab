# 杨氏双缝干涉：模型与操作

独立实验 `young-double-slit`，实验版本 **0.1.0**、协议 **v2 revision 0**、状态格式 **1**。计算使用 TypeScript 解析求值，场景与图表使用原生 SVG，控件、公式和说明弹窗使用平台公共能力。不增加依赖、WASM 或平台业务逻辑。

## 假设与范围

两条理想窄缝由同相、等振幅、同偏振的单色光照明，传播介质取真空。假定每条缝在观察屏上的单独场振幅都是 E₀；忽略有限缝宽的衍射包络及路径引起的小幅振幅变化。当前模型描述已经建立的稳态干涉，不模拟开光后的到达暂态，也不包含白光、非相干光、偏振变化或完整的双缝衍射。

参数和模型内部均使用 SI 单位；界面换算为 nm、mm、m：

| 量     | 范围         | 默认值  |
| ------ | ------------ | ------- |
| 波长 λ | 400–700 nm   | 550 nm  |
| 缝距 d | 0.10–1.00 mm | 0.25 mm |
| 屏距 L | 0.50–3.00 m  | 1.50 m  |
| 探针 y | −12–+12 mm   | 0 mm    |

全部参数组合满足 L≫d、|y|≪L 的近轴条件。观察屏范围固定，超出屏幕的前一 / 下一明纹按钮禁用；不移动屏幕刻度来掩盖范围变化。

## 几何光程与相位

双缝沿 y 轴排列，S₁=(0,+d/2)，S₂=(0,−d/2)，探针 P=(L,y)。正 y 向上。

```text
r₁ = √[L² + (y − d/2)²]
r₂ = √[L² + (y + d/2)²]
Δ = r₂ − r₁ = 2yd / (r₁ + r₂)
Δφ = 2πΔ / λ
```

代码采用最后一个等价形式计算 Δ，避免用米量级浮点数相减求纳米量级差值。Δφ 表示 S₂ 相对 S₁ 的传播相位滞后；因此在 P 的相位表示中，E₂ 相对 E₁ 的相位为 −Δφ。读数保留未折回的光程差级次 Δ/λ，不把不同级次都显示为同一个 0–2π 相位。

明纹满足 Δ=mλ，暗纹满足 Δ=(m+1/2)λ。定位按钮使用相同几何模型的反解，其中 a 是所需的光程差：

```text
y(a) = (a/2) √[1 + 4L²/(d² − a²)]，|a| < d
```

中央明纹为 y=0。前一 / 下一明纹按 y 方向寻找相邻的整数级次；第一暗纹定位到正 y 的半整数级次。显示的条纹间距 **Δy≈λL/d** 使用常见的近轴近似，场景条纹、强度曲线、游标和定位均使用几何光程差。

## 电场与周期平均光强

相位时间记为 u=t/T，以 S₁ 到达 P 的电场为相位参考：

```text
E₁/E₀ = cos(2πu)
E₂/E₀ = cos(2πu − Δφ)
E/(2E₀) = [cos(2πu) + cos(2πu − Δφ)] / 2
I/Imax = cos²(Δφ/2)，Imax = 4I₁
```

I₁ 是每条缝单独在 P 产生的光强。“看相位”的两条分场和合场都以 **2E₀** 归一化，分别为振幅 1/2、1/2 和至多 1；矢量和时间曲线使用同一相位参考和当前 u。实线 / 虚线与 S₁、S₂、Σ 图例同时区分分量。

屏幕明暗、强度曲线和相对光强显示周期平均值。它们在暂停、播放与相位回看时保持不变；不能将瞬时电场过零误画为暗纹。测试对瞬时场平方做独立周期平均，检查 `2⟨[E/(2E₀)]²⟩ = I/Imax`。

## 图示与真实时间

主场景的缝距、波前间距示意放大，路径图不按比例；路径数值采用真实物理参数。波前只示意从两缝向外传播，不作为测量相位、波长或光速的尺子。辅助线和波前均可关闭，场景大小不变。条纹颜色随 λ 变化，但只是显示器上的定性示意，不是色度学计算；黑底上的亮度透明度直接取周期平均相对光强。

真实时间尺度使用 `c=299792458 m/s`：T=λ/c、跨屏传播时间 L/c。默认 T≈1.83 fs、L/c≈5.00 ns。相位慢放的 **1× 每秒显示 0.4 个光学周期**，0.5× / 0.25× 只改变显示速度。相位时间轴可在 0–4T 回看；到末端暂停，再播放从起点开始。该慢放不代表把真实光速降到屏幕动画速度。

## 实验操作

- 左栏调节 λ、d、L，查看近似条纹间距和真实光学周期，独立切换光路、波前和明纹级次。
- 直接拖动屏上 P，或点击 / 拖动光强图与条纹带。探针方向键每次移动 0.05 mm，Shift 为 0.5 mm；Home 归零、End 到正边缘。下方滑块提供相同操作。
- 顶栏播放、暂停、回到相位起点和调节速度；中央时间轴回看同一相位。改变 λ、d、L 暂停并归零相位，保留探针的真实 y；移动探针不重置相位。
- “看光强 / 看相位”只切换观察内容。“探索”就地替换右栏图表；再次激活任一观察标签（包括当前项）返回图表，载入任务也返回图表并恢复观察标签焦点。
- 三个探索条件分别只改变波长、缝距或屏距，统一以 λ₀=550 nm、d₀=0.25 mm、L₀=1.50 m 为基准，显示实际 Δy/Δy₀。明纹位置按新模型求值，不用近似位置替代。
- “模型说明”包含假设、公式、符号和尺度；Escape 关闭并恢复入口焦点。语言、主题与图层切换保留物理状态。

## 状态、接入与验收

参数、探针、0–4T 相位、倍率、观察 / 探索页、图层和对照参数通过 `context.storage` 独立保存。恢复时校验对象、有限数、参数范围与枚举；坏数据使用默认值或限幅。始终暂停进入，不从存档自动播放。隐藏页面、pagehide、abort 或 dispose 会停止动画并保存，移除监听器、拖动捕获、工具栏和实验 dialog 内容。

明暗缩略图均纳入实验 manifest。首页首次完整缓存后，无需事先进入双缝实验即可断网打开，并使用公式、主题资源和状态恢复。平台版本保持 **0.2.0**，其他实验版本保持不变。按本次用户选择，本功能从 `origin/develop` 创建独立 `feat/young-double-slit` 分支，PR 指向 `develop`，不合并其他功能分支。

验收覆盖：几何明暗纹和正负对称性、近轴比较、近轴极小光程差的浮点稳定性、场的周期平均、参数边界与坏存档、鼠标和键盘、相位联动、探索基准、主题 / 语言与状态保持、资源释放、首次离线进入，以及 **1280×720 / 1440×900** 中英文和明暗主题的单屏操作。
