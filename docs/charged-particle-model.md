# 带电粒子在磁场中的运动

`charged-particle-magnetic-field` 0.1.0 使用协议 v2。对应《物理学教程》第四版下册 §11-7（81–89 页）；圆轨道与磁力不做功可交叉参照 [OpenStax University Physics Volume 2 §11.3](https://openstax.org/books/university-physics-volume-2/pages/11-3-motion-of-a-charged-particle-in-a-magnetic-field)。

## 约定与模型

- 粒子从坐标原点发射，初速度在 xy 平面内。屏幕向右为 +x，向上为 +y，朝观察者为 +z。磁场 `Bz` 均匀、静止，垂直于屏幕：⊙ 表示正值出屏，⊗ 表示负值入屏。点阵只标示方向，不编码强度。
- 电荷用元电荷 e（可为负或零）、质量用原子质量单位 u、初速用 km/s、磁场用 mT。内部位置、时间、速度和力按 SI 计算；读数含半径 cm、力 fN（10⁻¹⁵ N）、时间 μs（10⁻⁶ s）、动能 eV。发射方向从 +x 逆时针量起。
- 只考虑磁力 `F = q v × B`，即 `Fx = qBz vy`、`Fy = −qBz vx`。忽略电场、重力、阻力、辐射及相对论修正，不模拟平行于磁场的速度分量。
- 当 `v₀ > 0` 且 `qBz ≠ 0`，速度以有符号角速度 `Ω = −qBz/m` 转动；`qBz > 0` 时顺时针，`qBz < 0` 时逆时针。速度解析旋转后积分得到位置；`r = m v₀ / |qBz|`、`T = 2πm / |qBz|`。
- `F · v = 0`，所以 `|v|` 和 `K = mv₀²/2` 在单次运动中守恒。`qBz = 0` 时保持初速度并直线运动；`v₀ = 0` 时保持静止。后二者都不显示圆轨道半径或周期。

## 操作与显示

1. 左侧设置电荷、质量、磁场、速率和发射方向；也可从中央起点拖出初速度箭头，松开后提交发射条件。手柄支持 ↑ / ↓ 调速、← / → 调方向，按住 Shift 可大步调整。按 Enter 或点击顶栏“发射”。
2. 顶栏暂停 / 继续、选择 1× / 0.5× / 0.25×，或“回到发射位”保留本轮条件。1× 下，每 3 秒播放推进一个物理周期；没有圆轨道时推进 1 μs。回看上限为两个周期或 2 μs，到达后暂停，可从起点重播。滑块与关键时刻按钮均暂停并定位；重新调参暂停并回到发射位。
3. 场景、速度分量或动能图、时间游标和读数来自同一解析时间。虚线是预测轨道，蓝色实线采样已走过的路径。每轮按轨道范围自适应比例尺；比较轨道大小请看实体读数和比例尺。发射后的速度与力箭头分别按本轮恒定大小归一化，只用于看方向。
4. 分别开关轨迹和矢量，或在速度 / 动能图间切换，不改变参数、时间和场景比例。页面隐藏、离开和重新打开时暂停；隔离存档保存条件、回看位置、倍率和观察偏好。首页完整缓存后，未访问过本实验也可断网进入。

可从默认条件（`+1 e`、`1 u`、`+100 mT`、`100 km/s`、`0°`）开始：分别反转电荷或磁场，检查绕行方向；只加倍初速，比较半径（2 倍）、周期（不变）和动能（4 倍）；将电荷或磁场调至零，查看轨迹和磁力读数。
