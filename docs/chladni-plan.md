# 克拉尼图形实施计划

优先于 LC、杨氏双缝与带电粒子；作为 `experiments/chladni-plate` 独立插件，初始版本 0.1.0，状态格式 1。沿用 Bun、Vite 8、TypeScript、Lit 与原生 Canvas，不新增框架。平台版本保持 0.1.0。

## 模型与范围

- 方形、均匀、各向同性的铝薄板；外缘自由，中心小块固持以九个固定支承点近似。使用 Kirchhoff–Love 薄板弯曲能量的 Rayleigh–Ritz 近似，不能用一维弦或二维膜的频率冒充薄板频率。
- 低阶模态由正交多项式试函数求解；中心约束在系数空间消元，自由边界通过变分能量处理。以残差、正交性、对称性和阶数对比验证。真实夹具接触、材料不均匀及高阶工程精度不在第一版范围内。
- 周期点驱动力、模态阻尼、有限模态叠加得到复振幅与稳态响应，明确不模拟启动暂态。频率、力、阻尼及激励位置可调，模态预设一键定位共振频率。
- 砂粒沿低振幅区域迁移，采用固定步长、有种子的教学粒子近似；不宣称逐粒接触、弹跳和碰撞的精确仿真。多模态驱动显示「低振幅线」，不把任意瞬时过零线叫作波节。

## 单屏操作

左栏参数分为驱动 / 板材与撒沙；中央大板面，支持移动激励点与探针、撒沙、清空、暂停、慢放和时间回看；右栏切换沙纹、振型与共振观察。默认俯视，振型可倾斜观察；图层和视角不改变模拟状态。实时位移、速度、加速度从同一稳态相位与模拟时间计算。按用户补充要求，使用原生 WebGL2 绘制板面与砂粒，不引入渲染框架；不可用时回退 Canvas 2D。

保持黑白与少量蓝色、极小圆角；板面略有金属质感，砂粒细而清楚。默认中文、完整英文、明暗主题，1280×720 与 1440×900 均无需滚动完成主流程。高频板振动采用明示的相位慢镜头，砂粒时间和真实振动相位的换算在画面说明，不能伪装成实时振动。

## 功能提交顺序

1. 计划与路线优先级。
2. 薄板模态、阻尼受迫响应与可重现砂粒迁移；验证计算性能，只有确实需要时才在实验内部采用 Rust WASM。
3. 独立插件、Canvas 板面、单屏参数与三种观察、鼠标和键盘交互、中英文与主题。
4. 状态恢复、离线首次进入、模型与使用文档、桌面浏览器验收。
