# 协议 v1 revision 0

类型入口为 `src/infra/platform/protocols/v1`，旧入口 `src/infra/platform/contract.ts` 继续指向本版本。

`experiment.json` 保留原有字段：`id`、`version`、`apiVersion: 1`、`stateVersion`、双语 `title`、`description`、`tags`。省略 `apiRevision` 时使用 0。构建系统补入 `buildId`、`entry`、`thumbnail`、`resources` 形成 manifest。

`context` 提供 `locale`、`theme`、`buildId`、`signal`、`storage`，以及可选的 `toolbar`、`settings`。存储、挂载和生命周期用法见[接入协议](../plugin-contract.md)。v1 不注入 v2 的 `protocol`、`experiment` 或 `dialog` 字段。

公开组件契约为 `phy-button`：默认 slot、`variant`、`disabled`、`label` 和 `focus()`。公共组件样式随平台统一更新，既有按钮接口保持兼容。

新实验使用 v2。已有 v1 发布资源不必重建即可在新版平台继续加载。
