# 协议 v2 revision 0

类型入口：`src/infra/platform/protocols/v2`。本版本将公共控件、公式和 dialog 作为平台能力，并支持实验作者等元信息。

## experiment.json

```json
{
  "id": "example-experiment",
  "version": "1.0.0",
  "apiVersion": 2,
  "apiRevision": 0,
  "stateVersion": 1,
  "title": { "zh-CN": "示例实验", "en": "Example experiment" },
  "description": { "zh-CN": "实验说明", "en": "Experiment description" },
  "tags": { "zh-CN": ["力学"], "en": ["Mechanics"] },
  "author": { "name": "作者名称", "url": "https://example.com" },
  "repository": "https://example.com/repository",
  "license": "Apache-2.0"
}
```

| 字段                   | 必填 | 规则                                                     |
| ---------------------- | ---- | -------------------------------------------------------- |
| `id`                   | 是   | 小写字母开头，后续为小写字母、数字或短横线；与目录名一致 |
| `version`              | 是   | 实验发布版本，如 `1.0.0`                                 |
| `apiVersion`           | 是   | 本协议为 `2`                                             |
| `apiRevision`          | 否   | 最低所需修订号，非负整数，默认 0                         |
| `stateVersion`         | 是   | 正整数，决定保存状态的命名空间                           |
| `title`、`description` | 是   | 含非空 `zh-CN`、`en` 字符串                              |
| `tags`                 | 是   | 含两种语言的字符串数组，允许空数组                       |
| `author`               | 否   | 对象，含非空 `name`；`url` 可选                          |
| `repository`           | 否   | 绝对 HTTP / HTTPS 仓库网页地址                           |
| `license`              | 否   | 非空许可证标识字符串，例如 `Apache-2.0`                  |

作者 URL 同样要求 HTTP / HTTPS；URL 不包含用户名或密码。可选字段不自动继承平台值。当前仅校验许可证字段的非空字符串形式。

构建将元信息保留到 manifest，并计入 `buildId`。catalog 只保存列表摘要和协议要求；完整元信息通过 manifest 获取。

## Context

| 字段         | 用法                                                               |
| ------------ | ------------------------------------------------------------------ |
| `locale`     | 当前 `zh-CN` / `en`，后续变化通过实例 `update` 同步                |
| `theme`      | 实际 `light` / `dark`，已解析跟随系统设置                          |
| `buildId`    | 当前实验构建标识，可用于自定义元素名称                             |
| `signal`     | 实验退出或加载取消时终止                                           |
| `storage`    | `read(fallback)`、`readVersion(version, fallback)`、`write(value)` |
| `toolbar?`   | `setControls(element)` 挂载顶栏内容；`null` 清空                   |
| `settings?`  | `setControls(element)` 挂载实验设置；`null` 清空                   |
| `protocol`   | 当前平台选中的协议版本、实际支持的修订号及能力列表                 |
| `experiment` | 当前实验的只读元信息，包括作者、仓库、许可证                       |
| `dialog`     | `open(options)` 打开实验作用域的统一 dialog                        |

`experiment.apiRevision` 是实验的最低要求，`protocol.revision` 是平台实际提供的修订号，两者含义不同。

```ts
const hasMath = context.protocol.capabilities.components.includes("phy-math");
const hasDialog = context.protocol.capabilities.api.includes("dialog");
const authorName = context.experiment.author?.name;
```

当前 v2 revision 0 已包含所有公共控件和上述 API。未来新增兼容能力时在 `capabilities.ts` 记录首次支持的修订号。实验声明所需的最低修订，加载器在导入模块前检查。实验不直接导入平台注册表或服务。

## Dialog

```ts
const handle = context.dialog.open({
  title: "模型说明与推导",
  content: explanationElement,
  width: "md",
  returnFocus: helpButton,
});

handle.update({ title: "新的标题", width: 880 });
handle.close("done");
const result = await handle.closed;
```

| 选项              | 含义                                           |
| ----------------- | ---------------------------------------------- |
| `title`           | 必填、非空的 dialog 标题                       |
| `content`         | 必填 HTMLElement，正文由实验维护               |
| `footer`          | 可选 HTMLElement，底部内容                     |
| `width`           | 默认 `md`；可用预设或自定义正数 CSS px         |
| `closeOnBackdrop` | 默认允许点击遮罩关闭，`false` 禁用             |
| `initialFocus`    | 可选，打开后聚焦的元素                         |
| `returnFocus`     | 可选，关闭后恢复焦点的元素；默认记住打开前焦点 |

预设 `sm/md/lg/xl` 分别为 440/720/960/1200px，`full` 使用视口宽度减去两侧间距。所有尺寸都限制在视口内，两侧至少保留 16px。无效数值会抛出 `TypeError`。长正文内部滚动，标题和底部保持可见。

`update` 支持更新标题、正文、底部、宽度和遮罩策略。宽度或标题变化保留原正文节点。实验负责更新正文语言，关闭按钮的语言由平台同步。

`closed` 总是以结果完成：`reason` 为 `close`、`escape`、`backdrop` 或 `abort`，主动 `close(value)` 时附带字符串 `value`。重复关闭安全，关闭后更新无效。实验退出时自动关闭；退出后继续调用该作用域的 `open` 会抛出 `AbortError`。

正文可以是实验自己的 Web Component，或带 Shadow DOM 的 HTMLElement。这样实验能继续使用自己的 Lit 渲染和内容样式。

公共控件用法见[组件参考](../ui-components.md)。
