# 弹簧振子模型与操作规则

实验版本 **0.2.0**，状态格式 **2**，平台保持 **0.1.0**。采用 TypeScript 解析解，不增加框架、物理引擎或 WASM。

同一实验提供理想振动、阻尼自由振动、受迫振动三个物理模式。均采用水平线性弹簧和点质量，忽略弹簧质量，不包含干摩擦、非线性、碰撞与外力反馈。阻尼为与速度成正比的黏性阻尼，驱动为从 t=0 开始的简谐外力。

## 参数及单位

| 参数          | 范围               | 单位   | 适用范围        |
| ------------- | ------------------ | ------ | --------------- |
| 振幅 A        | 0–0.8              | m      | 理想模式        |
| 质量 m        | 0.2–5              | kg     | 全部模式        |
| 劲度系数 k    | 1–50               | N/m    | 全部模式        |
| 初相位 φ      | 0–2π，按周期归一化 | rad    | 理想模式        |
| 阻尼比 ζ      | 0–2                | 无量纲 | 阻尼 / 受迫模式 |
| 初始位移 x₀   | −0.8–0.8           | m      | 阻尼 / 受迫模式 |
| 初始速度 v₀   | −3–3               | m/s    | 阻尼 / 受迫模式 |
| 驱动力幅值 F₀ | 0–5                | N      | 受迫模式        |
| 频率比 r=Ω/ω₀ | 0–3                | 无量纲 | 受迫模式        |

由结构计算 `ω₀ = √(k/m)`、`T₀ = 2π/ω₀`、`b = 2ζ√(mk)`，b 的单位为 N·s/m。理想模式忽略阻尼和驱动参数；阻尼自由模式令 F₀=0。切换物理模式暂停并从 t=0 重启，保留上一轮参数供曲线比较。

## 模型与能量

统一方程：`m x″ + b x′ + kx = F₀ cos(Ωt)`。加速度由实际合力计算，阻尼力 `−bv` 始终与速度相反；受迫模式的加速度不必指向 x=0。Ω=0 时外力恒定，静态平衡位置变为 F₀/k，x=0 仍表示弹簧原长。

理想模式：`x = A cos(ω₀t+φ)`，`v = −Aω₀ sin(ω₀t+φ)`，`a = −ω₀²x`。保持原有简谐振动行为。

自由阻尼模式按三种解分开处理：

- 欠阻尼 `0≤ζ<1`：`ωd = ω₀√(1−ζ²)`，位移为指数衰减的正弦组合；位移图显示对应正负指数包络。零阻尼退化为自由简谐振动。
- 临界阻尼 `ζ=1`：`x = [x₀ + (v₀+ω₀x₀)t] exp(−ω₀t)`。
- 过阻尼 `ζ>1`：两个负实根指数项的叠加。

受迫模式使用“满足初始条件的自由解 + 周期特解”，包含真实启动暂态。无阻尼精确共振单独处理，受迫部分为 `F₀t sin(ω₀t)/(2mω₀)`，不能用无限大的稳态数值代替有限时刻的运动。无阻尼近共振使用 sinc 形式，避免两个巨大近似项相减造成精度损失。

所有模式计算 `Ek = mv²/2`、`Ep = kx²/2`、机械能 `E = Ek+Ep`。累计耗散 `Ed = ∫bv²dt`，外力功 `W = ∫Fv dt`，满足：

`E(t) + Ed(t) = E(0) + W(t)`。

W 使用解析积分，Ed 由能量收支求得并只修正浮点舍入造成的负零；独立数值积分同时检查功与耗散。理想模式机械能恒定；自由阻尼模式 W=0，机械能转为耗散能；受迫模式的 W 可以为负，曲线按实际符号显示。能量比例条始终表示当前机械能中的动能 / 势能占比，不能当作累计能量收支。

## 共振与相位

“看共振”仅在受迫模式提供，可切换幅频和相频图。图中工作点和键盘滑块修改同一个频率比，重启运动，并保留调整前的参数。响应图表示特定频率下的稳态 / 周期特解，不代表当前含暂态的小球瞬时振幅。

`X = (F₀/k) / √[(1−r²)²+(2ζr)²]`。

位移相对驱动力滞后 `δ = atan2(2ζr, 1−r²)`，位移特解为 `X cos(Ωt−δ)`。相位图以度显示，范围 0°–180°。

- 当 `F₀>0` 且 `0<ζ<1/√2` 时，非零频率的振幅峰值位于 `rᵣ=√(1−2ζ²)`。阻尼更大时不标虚假的非零频率峰值。
- ζ=0、r=1、F₀>0 时，没有有限稳态，也没有确定的有限响应相位；图线在奇点断开，明确显示共振增长说明。
- ζ=0、r≠1 时存在周期特解，但初始自由分量不衰减，完整运动通常不会趋于该特解。
- F₀=0 时响应幅值为零，相位未定义，不标振幅峰值。

## 状态与同步

三栏实验台在 1280×720、1440×900 浏览器内容区按 100% 缩放操作。左侧按“结构 / 初始 / 驱动”切换参数组；中央始终保留场景、读数、时间轴与关键时刻；右侧切换曲线、能量或共振，公式与探索任务共用下方固定区域。完整说明使用支持 Escape 关闭的弹窗。核心操作不依赖页面或参数面板滚动。

场景、矢量、受力、读数、曲线游标、能量条和公式使用同一模拟时间。播放速率 1× / 0.5× / 0.25× 只改变时间推进速度。观察视图和图层开关不改变物理状态。页面隐藏、离开或释放实例时暂停并保存；重新进入页面时恢复为暂停状态。

拖动时暂停并预览新的静止释放状态。理想模式右侧释放设置 A=|x|、φ=0，左侧释放设置 φ=π；其他模式设置 x₀=x、v₀=0，驱动相位也从 t=0 开始。拖动和键盘初始位移范围均为 ±0.8 m；运动本身不受该范围限制。零位移释放在有外力时仍可运动，零机械能时比例条避免除零。

参数滑块实时预览，一次调整只记录一次原参数作为对比。曲线按共同秒数时间轴显示，不同物理量分图并保留单位；长时间播放按两个 T₀ 的观察窗推进。临界、过阻尼及一般受迫运动不能将 T₀ 当作实际重复周期。曲线与解析解缓存，动画主要更新当前状态。

场景初始显示 ±0.8 m；运动超出时按当前观察窗的真实采样峰值留出余量缩小比例尺，标注实际位移范围，不截断物理数值。比例尺在同一观察窗内固定，不因关闭图层而变化。较大读数使用科学记数法。

速度、加速度箭头的方向表示正负，长度按当前观察窗各自的峰值缩放；不同物理量的箭头长度不可直接比较，绝对值以 m/s 和 m/s² 读数为准。驱动力箭头按 F₀ 缩放。场景下方列出弹簧力、阻尼力和驱动力；轨迹采样最近 0.2s 的真实位置。

## 旋转矢量与投影

场景顶部的“旋转矢量”开关默认关闭，只在理想模式启用。其他模式隐藏并禁用该图层，返回理想模式恢复偏好，不能将衰减或包含暂态的运动套进固定半径参考圆。

参考圆圆心 O 与平衡位置重合，半径为 A。OM 以 ω 逆时针转动，θ = ωt + φ；端点 M 的坐标为 (A cos θ, A sin θ)。垂直投影线从 M 连接到真实球心，水平方向始终满足 x = A cos θ。参考圆、球体、弹簧与拖动输入共用固定比例尺，最大振幅 0.8 m 的整个参考圆仍在画面内。

开关只改变辅助图层的可见性，不改变模拟时间、参数、播放状态、场景尺寸或球体位置。理想模式的三个观察视图共享开关。隐藏后端点退出键盘焦点顺序；振幅为零时收起退化的参考图形，小球保持静止。

拖动 M 或参考圆边缘会暂停并调整模拟时间，不改变初相位或振幅。跨越 0° 时选择最近的非负周期，避免跳回第一周期。端点支持方向键每次调整 5°，Shift 调整 15°，Home 定位最近的 0°。松手保持暂停，使用顶部播放按钮继续。

小球采用柔和的蓝色球面渐变、细轮廓和局部微光；参考线降低对比度并绘制在弹簧和小球后方。辅助图层淡入淡出 180 ms，系统要求减少动态效果时直接切换。

## 关键时刻

理想模式保持原行为：考虑初相位，在非负时间中选择对应时刻。右端点相位 0，向左经过平衡位置相位 π/2，左端点相位 π，能量相等相位 π/4。

阻尼 / 受迫模式从当前时间向后搜索最多 12T₀，采样括住根并二分定位。右端点要求 v=0 且 a<0，左端点要求 v=0 且 a>0；两者不按 x 的正负分类，恒定外力可能让左右端点都处于 x>0。“经过 x=0”求位移过零，“动能 = 势能”求 mv²=kx²；排除静止零信号。未找到时说明搜索范围，不制造不存在的端点或过零时刻。

仅理想模式能直接使用“平衡位置加速度为零、速率最大”“|x|=A/√2 时等能”“振幅翻倍能量四倍且周期不变”等结论。新模式的说明和公式随当前模型切换。

## 存储、迁移与独立发布

通过 `context.storage` 保存到 `phy-lab:experiment:spring-oscillator:state:2`。状态包括物理参数、暂停时间、速率、观察视图、参数分组、能量 / 响应图类型、公式 / 任务标签、箭头与旋转矢量偏好、上一轮曲线参数，以及原有探索进度。

优先读取并校验格式 2；缺失或根结构损坏时尝试 `storage.readVersion(1)`。旧参数默认理想模式，保留暂停时间、初相位、图层、曲线和探索进度，为新字段补默认值。迁移只写格式 2，不修改或删除格式 1，便于回滚。无效字段按有限值、范围和枚举校验，未知 / 损坏数据回退安全默认值；时间限制在 0–1,000,000 s。

仅 `experiment.json` 升级到 0.2.0、stateVersion=2；根 package.json 仍为 0.1.0。构建继续生成独立不可变地址，现有 Service Worker 缓存实验所有模式所需资源。新实验构建准备就绪后，下次进入启用，运行中的旧实例不切换。发布步骤见 [发布与更新](release-and-update.md)。

## 验证

模型测试覆盖原有理想振动、所有阻尼区间及临界两侧连续性、初始条件、合力与功率、能量收支、恒力平移、共振和近共振，并与独立 RK4 积分的位移、速度、外力功和耗散对照。存档测试覆盖旧格式迁移、新格式优先级与损坏数据。

浏览器测试覆盖三个模式、实际图形 / 读数一致性、拖动与键盘、共振图工作点、不可达关键时刻、图层偏好、离线刷新及状态恢复、大位移缩放，并在两个目标尺寸、中英文、明暗主题和各参数 / 观察标签下检查核心内容无溢出。原有旋转矢量、平台更新、开发缓存退出、子路径发布等验收继续保留。
