# 弹簧振子模型与操作规则

实验版本 0.1.1，状态格式 1。采用 TypeScript 解析解，不需要数值积分或 WASM。模型条件：水平理想弹簧、无摩擦、无外力驱动；拖动时用户手动设定初始状态，松手后按自由振动计算。

## 参数及单位

| 参数       | 范围               | 单位 |
| ---------- | ------------------ | ---- |
| 振幅 A     | 0–0.8              | m    |
| 质量 m     | 0.2–5              | kg   |
| 劲度系数 k | 1–50               | N/m  |
| 初相位 φ   | 0–2π，按周期归一化 | rad  |

`ω = √(k/m)`，`T = 2π/ω`。

`x = A cos(ωt+φ)`，`v = -Aω sin(ωt+φ)`，`a = -ω²x`。

`Ek = mv²/2`，`Ep = kx²/2`，`E = kA²/2`。

## 状态与同步

场景、矢量、读数、曲线游标、能量条和公式使用同一模拟时间。播放速率只改变时间推进速度。页面隐藏时暂停；重新进入页面时恢复暂停时间。

拖动时暂停并预览新的静止释放状态。右侧释放设置 A=|x|、φ=0，左侧释放设置 φ=π。振幅为零时静止，能量比例条避免除零。

参数滑块实时预览，在一次调整中保存调整前参数作为对比。曲线按共同秒数时间轴显示；不同物理量使用分图与独立单位。长时间播放按两周期观察窗口推进。快速旧曲线自动增加采样数量，曲线形状缓存，播放主要更新场景与游标。

箭头的方向表示正负，长度按当前参数下各自的最大值缩放。不同物理量的箭头长度不可直接比较；绝对值以 m/s 和 m/s² 读数为准。运动轨迹采样最近 0.2s 的真实位置。

## 旋转矢量与投影

场景顶部的“旋转矢量”开关默认关闭，选择保存在实验自己的 LocalStorage 状态中。旧版状态没有该字段时按关闭处理，状态格式保持向后兼容。

参考圆圆心 O 与平衡位置重合，半径为 A。OM 以 ω 逆时针转动，θ = ωt + φ；端点 M 的坐标为 (A cos θ, A sin θ)。垂直投影线从 M 连接到真实球心，水平方向始终满足 x = A cos θ。参考圆、球体、弹簧与拖动输入共用固定比例尺，最大振幅 0.8 m 的整个参考圆仍在画面内。

开关只改变辅助图层的可见性，不改变模拟时间、参数、播放状态、场景尺寸或球体位置。三个观察模式共享开关。隐藏后端点退出键盘焦点顺序；振幅为零时收起退化的参考图形，小球保持静止。

拖动 M 或参考圆边缘会暂停并调整模拟时间，不改变初相位或振幅。跨越 0° 时选择最近的非负周期，避免跳回第一周期。端点支持方向键每次调整 5°，Shift 调整 15°，Home 定位最近的 0°。松手保持暂停，使用顶部播放按钮继续。

小球采用柔和的蓝色球面渐变、细轮廓和局部微光；参考线降低对比度并绘制在弹簧和小球后方。辅助图层淡入淡出 180 ms，系统要求减少动态效果时直接切换。

## 关键时刻

定位按钮考虑当前初相位，在非负时间中选择对应时刻。右端点相位 0，向左经过平衡位置相位 π/2，左端点相位 π，能量相等相位 π/4。

端点速度为零、加速度最大；平衡位置加速度为零、速率最大。能量相等时 |x|=A/√2。振幅加倍不改变周期，总能量四倍。一次完整振动中，动能最大出现两次。

## 验证

模型测试覆盖不同质量、劲度、相位和时间的能量守恒，以及关键时刻、振幅变化、能量半周期和无效参数校验。浏览器测试验证拖动、暂停、参数修改、初相位、零振幅、键盘、离线和版本切换。
