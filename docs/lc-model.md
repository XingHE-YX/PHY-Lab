# LC 电磁振荡模型

实验 ID 为 `lc-oscillator`，版本 **0.1.0**，使用 **v2 revision 0** 协议，存档格式 **1**。这是独立的前端插件，沿用 Bun、Vite、TypeScript 与 Lit；电路和曲线使用原生 SVG，不增加运行依赖或 WASM。

参数滑块、播放速度、图层复选框和观察 / 辅助标签使用平台公共控件，首页归入“电磁学”。公式使用平台 `phy-math`，KaTeX、样式及字体由平台统一提供；模型说明通过 `context.dialog` 打开，随语言更新，关闭后恢复焦点，退出实验时自动关闭。存储保留原 `stateVersion: 1` 的命名空间，新增开关参数、残余初态与瞬态记录均兼容补默认值，已有参数、暂停时间与偏好可以直接恢复。

## 模型与初态

闭合阶段使用理想、线性的电感 L 和电容 C，忽略闭合回路的损耗，可持续等幅振荡。电源只负责在实验前给电容准备初始电压 U₀；开始振荡前已移除，不持续驱动回路。重新充电的初态为 `q(0) = C U₀`、`I(0) = 0`；重新闭合则使用上一次断开后剩余的电荷、电流。模型基础见 [OpenStax：LC 回路振荡](https://openstax.org/books/university-physics-volume-2/pages/14-5-oscillations-in-an-lc-circuit)。断开阶段单独启用下述非理想开关近似。

内部全部使用 SI：L 为 H，C 为 F，电压为 V，时间为 s，电荷为 C，电流为 A，能量为 J。界面显示 mH、μF、ms、μC、mA、mJ。L 范围 10–200 mH，C 范围 10–200 μF，U₀ 范围 −12–12 V；负电压改变初始极性。L、C 不接受零或负值，零电压是有效的无储能静止状态。

## 电流方向与解析解

`q` 是电容上极板的带符号电荷，`U꜀ = q/C` 是上极板相对下极板的电压。图中正电流从上极板流出，沿上方导线向右，经过电感流向下极板，即顺时针。因此本实验采用 `I = −dq/dt`，与把电流定义为流入上极板时的符号相反。

```text
L dI/dt = U꜀ = q/C
L q″ + q/C = 0
ω = 1/√(LC)              T = 2π√(LC)              f = 1/T
q(t) = C U₀ cos(ωt)
I(t) = C U₀ ω sin(ωt)
U꜀(t) = U₀ cos(ωt)
```

闭合阶段的场景、箭头、读数、曲线与游标由同一初态和物理时间解析求值。重新闭合使用一般初态：`q = q₀ cos(ωt) − I₀ sin(ωt)/ω`、`I = q₀ω sin(ωt) + I₀ cos(ωt)`。电荷与电流使用不同单位、独立纵轴；图表每四个周期推进一次窗口，时间不回绕，也不在窗口末尾停止。在准备状态，曲线是闭合后的预览。

## 断开瞬态近似

点击后开关立即弹开，不等待电流过零。电容电压与电感电流在断开瞬间连续，断开不是清空储能。模型在触点两端加入电容 Cₚ、对称击穿钳位支路和瞬态等效阻尼 Rₜ。钳位建模参考 [TI：电感负载断开与能量释放](https://www.ti.com/document-viewer/lit/html/slvaf04) 的思路；这里采用教学等效支路，不是实物机械触点或等离子体模型。

“开关”参数组可调整 Cₚ（0.1–10 nF）、击穿阈值 Uᵦ（50–2000 V）和 Rₜ（50–2000 Ω）。默认 **1 nF、600 V、500 Ω**；钳位动态电阻 Rₐ 固定为 **20 Ω**。这些是示例假设，未经器件实测标定。Rₜ 只属于断开瞬态的等效损耗，不给闭合阶段添加阻尼。修改开关参数只用于下一次断开，已有记录保留原参数。

```text
C dU꜀/dt = −I
L dI/dt = U꜀ − Uₛ − Rₜ I
Cₚ dUₛ/dt = I − Iₐ(Uₛ)
Iₐ(Uₛ) = sign(Uₛ) max(|Uₛ| − Uᵦ, 0) / Rₐ
Eₚ = Cₚ Uₛ²/2
d(E꜀ + Eʟ + Eₚ)/dt = −Rₜ I² − Uₛ Iₐ
E₀ = E꜀ + Eʟ + Eₚ + 累计阻尼耗散 + 累计击穿耗散
```

采用可精确求解钳位分支的隐式中点步进，通过步长加倍估计误差并自适应细分；每个接受步的能量变化等于计算出的耗散。计算独立于动画帧率，使用独立显式 RK4 对照验证。对数分布输出采样同时保留快速上升沿与较长尾部，额外保留真正的峰值采样；读数和游标使用实际求解采样，不用显示插值制造能量损失。稳定时间按剩余振荡能量低于初始能量的 `10⁻¹⁰` 定义，数值终止时把这一可忽略尾部的能量计入阻尼耗散。

右侧自动打开“瞬态”：电压图分别显示开关两端 Uₛ 与电感 Uʟ，电流图显示 I，能量图显示 E꜀、Eʟ、Eₚ 与累计耗散。摘要显示最大绝对开关电压、稳定时间、当前累计耗散和能量误差。默认放大冲击区，可选择全过程；横轴始终使用真实 μs。中央保留独立的 U꜀ 与 Uₛ 读数。接触处的红色放电标记仅在模型击穿功率大于零时显示，强度来自该功率。

记录按约四秒的非匀速慢放展示（倍率继续生效），并明确标注；可暂停、重放、拖动曲线或用方向键 / Home / End 回看。结束后电容保留计算出的残余电荷。再次闭合会先结束慢放，并以计算出的最终残余状态开始新的自由振荡；闭合时触点电容的放电冲击不在本模型范围内。重新充电是独立操作，会主动恢复设定电压并清除当前记录。

## 能量与关键时刻

```text
E꜀ = q²/(2C)             Eʟ = L I²/2
E꜀ + Eʟ = C U₀²/2
dE꜀/dt = −U꜀ I          dEʟ/dt = U꜀ I
```

按正初始电压，0 时电容充满、电流为零；T/4 时电荷为零、电流顺时针达到峰值；T/2 时电容反向充满；3T/4 时电流逆时针达到峰值。负电压反转这些极性与方向，能量不变。T/8 时两种能量相等，`|q| = |CU₀|/√2`。零电压时这些状态退化，不宣称存在非零峰值或定义良好的归一化量。

总能量不变，两种能量都以 T/2 为周期。增大电压不改变固有周期；电压加倍使总能量变为四倍。单独将 L 或 C 变为四倍使 T 加倍。保持 C、U₀ 不变将 L 变为四倍时，电流峰值减半。

## 观察模式与机械类比

三种观察共享同一回路与时间。看振荡分别显示 q / μC 和 I / mA，避免不同单位共用纵轴。看能量使用 mJ 的同一纵轴：电场能蓝色实线、磁场能绿色虚线、总能量中性点线；中央能量比例条始终显示 E꜀、Eʟ 和总量。零储能时比例条为空，关键时刻按钮禁用。

类比弹簧来自两组方程的对应关系：

```text
L q″ + q/C = 0            ↔          m x″ + kx = 0
L ↔ m                    1/C ↔ k
q ↔ x                    −I = q′ ↔ v
E꜀ ↔ 弹性势能            Eʟ ↔ 动能
```

类比图的球心位置为 `q/|CU₀|`，速度箭头和绿色曲线为 `−I/Iₘ`；蓝色曲线为 `q/|CU₀|`。负电压使初态位于另一端。两者各自除以正峰值，均为无量纲；不是把电荷与位移、电流与速度的单位视作相同。原 LC 回路和读数始终可见，不引用弹簧实验代码。U₀ = 0 时峰值为零，类比区显示说明，不显示无定义的归一化图形。

## 探索预设

右侧“探索”隐藏图表，以独立面板展示三张任务卡片，每张包含说明和“载入预设”按钮。激活任意观察标签（包括当前选中的标签）返回图表；载入预设后暂停并返回对应视图，焦点移回观察标签。打开探索、切换公式和观察标签不改变参数、时间或播放状态。

所有比较使用共同基准 `L = 50 mH、C = 100 μF、U₀ = 6 V`，不会把当前已被修改的其他参数偷偷作为比较基准。Tref、Eref、Iref 分别为该基准的周期、总能量与峰值电流。参数栏的派生读数下方始终显示基准与比值，按实际当前参数计算，切换探索和图表时均可查看。

1. **电压加倍**：恢复基准后将 U₀ 设为 12 V，准备态 t = 0，显示能量视图；T 不变、E 为四倍。
2. **电感变为四倍**：恢复基准后将 L 设为 200 mH，准备态 t = 0，显示振荡视图；T 为两倍、Iₘ 减半。
3. **电荷为零**：恢复基准并闭合，暂停在 T/4，显示能量视图；q = 0，I 达峰值，能量全部在电感。

继续手动修改参数、运行或回看即可探索，按钮不宣称用户已完成任务。观察标签只切换显示内容；载入探索预设才会改变参数或时间。

## 时间、操作与恢复

闭合阶段默认每秒播放推进 4 ms 物理时间，提供 1×、0.5×、0.25× 播放倍率。倍率仅影响推进速度；L、C 仍真实地改变周期，界面持续标注物理时间与播放时间比例。没有运行时长限制，不显示时间进度条。

点击或拖动普通曲线会暂停并定位到同一物理时间，关键时刻定位第一个周期中的时刻。图示开关保留透明虚线边框，点击、Enter 与空格操作真实通断：闭合立即运行，断开立即计算并展示瞬态。顶栏负责暂停 / 继续、回到起点和速度选择；暂停不会弹开开关。瞬态回放有独立的暂停 / 继续文案。

“重新充电”和修改回路 L、C、U₀ 会暂停、重新准备并回到 t = 0，清除当前断开记录；不模拟外部电源充电暂态。场图层、语言、主题与观察标签只改变显示内容。帮助支持 Escape 并恢复焦点。

存档通过平台 `context.storage` 隔离保存参数、暂停时间、开关状态、观察 / 探索 / 图层偏好和播放倍率，恢复后保持暂停。准备状态强制 t = 0；坏数据使用有限值默认值或限定在合法范围，不影响其他实验。新增偏好字段有默认值，格式仍为 1。切后台、离开或释放实例时暂停并取消动画帧、移除监听器与顶栏控件。实验必需资源由独立发布清单纳入平台缓存，首页首次完整缓存后，无须事先进入 LC，即可断网打开并恢复状态。

## 场的表示范围

电场箭头从正极板指向负极板，随电荷变号反向；磁场随图示线圈的电流方向反向。箭头强弱分别按 `|q|/|CU₀|`、`|I|/Iₘ` 表示，不是空间场求解，不能比较两种场的箭头长度。L、C 不足以唯一确定实际线圈与极板几何，因此不显示没有依据的 V/m 或 T 数值。电路符号大小不代表参数对应的真实器件尺寸。

验证使用独立 RK4 积分对照、数值微分、KVL、电荷连续关系和能量功率平衡，覆盖正负电压、无储能与参数端点。浏览器检查同步读数、无限运行、瞬态的立即断开与残余电荷、模型参数记录固定、后台与退出暂停、存档与离线恢复；1280×720 与 1440×900 的观察、探索、瞬态和两组参数均检查中英文和明暗主题。
