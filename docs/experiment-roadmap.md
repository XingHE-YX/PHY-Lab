## 第一项的实施要点

状态：**已完成（弹簧振子 0.2.0 / 状态格式 2）**。理想、阻尼、受迫三个物理模式、分组参数、幅频 / 相频工作点、真实关键时刻、单屏双语与明暗主题、旧存档迁移及离线恢复均已接入。计算与操作规则见 [弹簧模型](spring-model.md)，下列要点作为后续维护依据。

- **模型分开，观察同步。** 理想、阻尼自由、受迫三个物理模式，共用 `m x″ + b x′ + k x = F₀ cos(Ωt)` 的模型定义。自由模式令 F₀ = 0，理想模式再令 b = 0。明确 `ω₀ = √(k/m)`、`ζ = b / (2√(mk))` 和驱动频率 Ω 的区别。
- **计算继续使用 TypeScript。** 保留理想解析解，为阻尼和周期驱动增加解析求值，包含暂态、欠 / 临界 / 过阻尼、零阻尼及精确共振的特殊情况。场景、读数、曲线和时间回看统一取同一状态，不能只画稳态曲线来代替启动过程。
- **控制保持一屏。** 顶部切换物理模式；左侧按“结构 / 初始 / 驱动”分组切换参数，使用 ζ 控制阻尼并显示 b 的单位与换算值；初始位移不能继续误标成受迫稳态振幅。中央保留弹簧、小球、拖动释放、时间轴与实时读数；右侧按标签切换现有观察视图及共振响应图，不能向下堆叠面板。
- **共振包含幅值与相位。** 频率控制优先展示 Ω/ω₀，共振曲线标注当前工作点；区分暂态运动与稳态响应。相位差约定为位移相对驱动力的滞后。位移稳态振幅峰值仅在 `0 < ζ < 1/√2` 时位于 `Ωᵣ = ω₀√(1−2ζ²)`，其余情况按模型解释；零阻尼精确共振没有有限稳态振幅。
- **能量解释随模型变化。** 理想模式保持机械能守恒；阻尼模式显示机械能下降与累计耗散；受迫模式显示外力功与耗散，按 `E机械(t) + E耗散(t) = E机械(0) + W驱动(t)` 校验。加速度按合力计算，不再笼统解释为“始终指向平衡位置”。
- **保留准确的图形语义。** 小球沿用柔和的蓝色立体质感，可增加有物理意义的阻尼器、驱动力箭头和衰减包络。原有固定半径、匀速旋转的矢量图限于理想模式；新模式先不显示该图层并解释适用范围。禁止把衰减或含暂态的运动硬套成固定半径投影。
- **关键时刻与状态兼容。** 新模式的端点、过平衡点与能量相等时刻按模型求取，不沿用理想振动的固定相位；不存在时给出说明。修改参数重新开始并保留上一轮对比；旧存档按理想模式读取。升级实验自身版本，有存储结构变化时提供迁移，不改平台版本来代表实验更新。

实施时按“模型与能量 → 单屏参数与场景 → 共振图与关键时刻 → 状态迁移与验收”拆分功能提交。重点检查临界阻尼两侧连续性、零阻尼共振、能量收支、任意时间回看、旧存档，以及 1280×720 和 1440×900 下的核心操作。

## 第二项的完成记录

状态：**已完成（机械波实验台 0.1.1 / 状态格式 1）**。作为独立插件接入，无新增框架、运行依赖或 WASM；平台与弹簧实验版本保持不变。模型和操作见 [机械波模型](mechanical-waves-model.md)。

- 单次向上 / 向下波包与平滑启动的连续波，按传播速度推进，介质质点保持固定横坐标。
- 固定端反相、自由端同相；入射 / 反射 / 合成波可独立显示。左边界开放，只模拟右端反射，避免将观察段误作两端共振腔。
- 已建立的驻波、波节 / 波腹标记与定位、局部振幅、关键时刻和三个探索预设，明确瞬时位移为零与波节的区别。
- 可拖动探针、横向速度箭头、位移 / 速度 / 加速度读数、空间剖面与单点时间记录，共用一个模拟时间。
- 中英文、明暗主题、桌面单屏控制、独立状态恢复及首次首页缓存后的离线访问均纳入验收。

功能按“传播与质点跟踪 → 边界反射与图层 → 驻波与探索 → 状态 / 离线 / 文档”分别提交。其后为独立的二维驻波「克拉尼图形」，LC、双缝与磁场依次列为第 4–6 项。

## 第三项的完成记录

状态：**已完成（克拉尼图形 0.1.1 / 状态格式 1）**。作为独立插件实现，不新增框架或运行依赖，平台和已有实验版本不变。模型、限制与操作见 [克拉尼模型](chladni-model.md)。

- 自由外缘、中心九点位移支承近似的铝薄板；预计算 24 个弯曲模态，运行时计算点力驱动的阻尼稳态响应，明确不包含启动暂态。
- 原生 WebGL2 板面、砂粒与放大形变，提供俯视 / 倾斜视角；不可用或上下文丢失时回退 Canvas 2D，保留状态。
- 砂粒按有种子的低振幅迁移近似形成纹路，固定内部步长与检查点支持确定性回看；不是精确接触、弹跳与颗粒碰撞仿真。
- 激励点与测点可拖动、点击或用键盘移动；三种观察、共振工作点、测点曲线和读数共用一个物理状态。主操作保持桌面单屏。
- 原生 Web Audio 音高跟随驱动频率，慢镜头不降调；实验设置提供持久静音开关，暂停与退出停止声音。按用户要求移除“步进 1/16 周期”按钮。
- 验收覆盖计算残差与收敛、砂粒回看、状态恢复、双语明暗布局、首次离线进入、显卡回退、实际音频输出及资源释放。

功能按“模型与砂粒 → 板面与单屏交互 → 声音与静音 → 文档与验收”分别提交。下一项为 LC 电磁振荡。
