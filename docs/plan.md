# PHY Lab 实施计划

平台版本：0.1.0。技术栈：Bun、Vite 8、TypeScript、Lit Web Components。复杂计算可在实验内部使用 Rust WASM；首个弹簧实验使用 TypeScript 解析解。

后续排期见 [实验制作顺序](experiment-roadmap.md)，统一遵循 [实验制作规范](experiment-guidelines.md)。本分支从 `main` 创建，仅新增克拉尼实验；弹簧阻尼与机械波在独立 PR 中维护。

## 目标

建立纯前端、可离线使用的物理实验工作台。实验拥有独立入口、资源、版本和状态格式，平台通过公开接口加载。首次完整缓存后，尚未打开过的实验也能离线进入。

## 目录

- `src/ui/{components,layouts,styles}`：基础控件、工作台和设计变量。
- `src/pages`：工作台与实验路由页面。
- `src/infra/{locales,platform}`：平台语言、公开插件协议、目录加载。
- `src/services`：设置、存储、路由、主题、离线与更新。
- `experiments/<id>`：实验页面、组件、模型、文案和资源。
- `experiments/<id>/wasm`：可选 Rust 计算模块，随实验发布。
- `scripts/*.ts` 和 `justfile`：构建、开发、预览与清单生成。

## 架构与版本

平台版本只读取根 package.json；实验版本只读取各自 experiment.json。接口版本与状态格式版本独立。资源使用内容 hash，已发布的资源不可变。

生产环境读取 catalog.json，然后读取实验 manifest.json，再动态加载独立 ESM。目录不固化在平台 bundle 中。新增实验仅发布资源并更新目录；更新平台不强制重建实验。

每个 manifest 记录完整资源列表、大小和 SHA-256。实验与 Lit 运行时独立打包，使用公开上下文、CSS tokens 和基础 Web Component 控件，禁止引用平台私有实现。

## 功能与提交顺序

1. 文档、Apache 2.0 许可证、工程规范。
2. TypeScript 构建脚本、Vite 8、justfile 和独立实验发布。
3. 黑白蓝工作台、搜索、菜单、语言、主题和 LocalStorage 设置。
4. 弹簧解析模型、SVG 场景、拖动释放、播放和参数控制。
5. 三个观察模式、同步曲线、能量、关键时刻、公式及探索任务。
6. Service Worker、完整离线缓存、独立更新、状态恢复。
7. 集成验证、使用文档和发布规范完善。

每个完成的功能单独提交 commit；修复对应明确的验证结果。

## 弹簧实验

始终展示主场景。所有显示从同一模拟时间计算：

`ω = √(k/m)`，`T = 2π√(m/k)`，`x = A cos(ωt+φ)`，`v = -Aω sin(ωt+φ)`，`a = -ω²x`。

能量：`Ek = mv²/2`，`Ep = kx²/2`，`E = kA²/2`。

拖动时暂停，松手从静止释放，左右释放分别使用相位 0 或 π。参数修改重新开始并保留上一轮曲线；进阶初相位在全部视图中生效。时间游标、模式切换、关键时刻共享时间。后台暂停，离开实验销毁动画。

看运动：位移、周期、振幅与方程。看变化：分图显示位移、速度、加速度及箭头。看能量：动能、势能、总能量及比例条。蓝色位移/势能、绿色速度/动能、红色加速度，只在科学内容中使用语义颜色。

源素材存在未标单位的共轴显示、加速度超出纵轴、后续场景忽略初相位、场景相互分离等问题。新实现保持单位、相位、质量与刚度关系一致。

## 离线与更新

Service Worker 缓存平台和目录中所有兼容实验的必需资源；全部校验通过才显示离线就绪。设置保存于 LocalStorage，资源与 worker 元信息保存于 Cache Storage。

平台新构建先完整安装，等待用户启用；保存实验状态后协调刷新。实验新构建独立下载，当前实例固定旧构建；下次进入时使用已就绪的新构建。失败继续使用原版本，清理不影响仍在使用的资源。

不可变资源先上传，校验成功后再切换 catalog 或平台发布指针。目录和发布清单使用网络检查与缓存回退；精确 hash 资源缓存优先。HTTP 资源错误不得回退到 HTML。

## 验收

- 首次仅打开工作台，缓存完成后断网，进入实验并刷新仍正常。
- 独立发布新实验不改变平台包与版本；单独更新平台不改变实验包。
- 任意初相位和参数下状态同步、能量守恒；振幅加倍能量四倍、周期不变。
- 暂停任意时刻可判断位置、速度方向、加速度方向和能量分配。
- 中英文、浅深色、减少动画、键盘与鼠标操作可用。桌面宽度至少 1280px，窄窗口只显示桌面尺寸提示。
- 生产构建、类型检查、模型测试和关键浏览器流程通过。

## 已实现

工作台、独立插件构建、弹簧三种观察模式、拖动释放、时间控制、公式与探索任务、完整离线缓存、独立更新和多标签页状态保存均已实现。界面改为桌面专用三栏实验台，运动轨迹使用真实解析解采样。

验证包括物理模型测试、浏览器交互与更新测试、首次未打开实验的离线访问、根路径和 /phy/ 子路径部署。

### 弹簧实验 0.1.1：旋转矢量

- 保留柔和立体感的蓝色小球，增加参考圆、角度弧、OM 矢量和垂直投影。
- 参考图层可独立隐藏，默认关闭；保存显示偏好，切换不改变时间、播放状态和场景比例。
- 拖动矢量端点或参考圆调整同一模拟时间，支持键盘操作，初相位保持不变。
- 固定比例尺覆盖 0–0.8 m 振幅；零振幅隐藏退化图形，支持中英文和浅深色。
- 实验独立更新到 0.1.1，平台保持 0.1.0，沿用已有离线缓存与发布流程。

### 克拉尼图形 0.1.0：薄板二维驻波

- 新增独立 `chladni-plate` 插件，使用 TypeScript 预计算的 Rayleigh–Ritz 薄板弯曲模态与受迫稳态响应；自由外缘，中心九点位移约束近似小块支承。保留 24 个模态，测试残差、约束、正交性与阶数收敛。
- 原生 WebGL2 绘制板面与砂粒，支持俯视 / 倾斜和真实变形网格拾取，显卡不可用时回退 Canvas 2D。有种子的低振幅砂粒迁移属于教学近似，支持确定性时间回看。
- 参数分组、沙纹 / 振型 / 共振观察、激励与测点拖动、同步读数与曲线、模态预设和模型说明保持 1280×720、1440×900 中英文与明暗主题单屏操作。
- 原生 Web Audio 振动音跟随实际驱动频率，慢放不降调。设置 → 实验设置中保存静音偏好；暂停、后台与离开时停止声音。移除本实验的单步按钮，保留时间轴。
- 独立版本 0.1.0、状态格式 1，保存砂粒种子、周期数、参数、探针、图层和静音；首次首页完整缓存后支持尚未进入过的实验离线访问，音效不依赖网络。
- 验收涵盖参数边界、存档恢复、砂粒重现、视角拾取、显卡回退、音效及资源释放。详见 [克拉尼模型](chladni-model.md)，下一项为 LC 电磁振荡。
